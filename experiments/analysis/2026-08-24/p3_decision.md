## 2. 最终决策

### 决策：形态 A 变体——13ch 线性小型学习型 FNO

| 决策项 | 取值 | 理由（→ 证据） |
|---|---|---|
| 形态 | **A 变体**（小型学习型 FNO，主攻） | 首选（spec §4）；C、B 纯学习出局（§0）；保底参照为 B-注入 |
| 输入特征 | **13ch**：force(4) + displacement(3) + velocity(3) + acceleration(3) → disturbance(2)（E 系列问题定义；FNO 侧再拼 grid 通道 = 14 维，与 F5 注入 fc0 完全同构） | diff8ch/raw8ch 出局（证据表第 4 行）；13ch 余量充足且免疫 float32（第 5 行） |
| 非线性 | **线性（activation="none"）** | 发现 1：算子精确线性（rl2 ~1e-15），非线性只加 GELU 互调失真（E31 2.03e-4 残差即互调 + 高频无约束）；发现 8：线性结构可精确嵌入解析逆算子；P1：容量非瓶颈（modes 128→252 无学习收益） |
| modes | **128**（判定门：升 252） | P2 频谱净化（18-250 Hz 无伪影、d 带能量占比 6.1e-5，第 3 行）→ 截断根因消除，128 覆盖音调带与物理带；P1：学习极限与截断无关（252 仍有 5.97e-3）；"简易"（modes 128 vs 252 参数约 2×） |
| width | **64**（判定门：升 128） | 候选 A 既定边界（spec §4）；逐 bin 线性映射自由参数需求低（每 bin 仅 (13+1)×2 复参），width 64 表示能力充足；P1 用 128 达 6e-3 是优化瓶颈非容量（第 1 行） |
| 训练数据档 | **扩产全量 5700**（5000/500/200，preroll 0.5s + substeps 5，配方同 P2，输出 `~/data/neural_operator_3`） | 生成成本极低（600 样本 40s @4 workers → 5700 ~6-7 min，一次性）；学习型 SGD 泛化需要训练量（发现 4 的"非样本量限制"是闭式 LS 结论，不适用于 SGD）；val/test 统计可靠（50→500/200）；T6 小跑可用现成 500/50/50 |
| 训练策略 | 500ep 起步（b64/lr2.83e-3，与 P1 可比）；未达 1e-4 按 E 系列经验低 lr 链式微调（计划 Task 6 Step 2 既定） | P1 500ep = 5.97e-3（优化瓶颈）；E31 链式微调（b8 lr5e-5 × 1200ep）= 2.03e-4 → 长训 + 低 lr 是突破学习极限的唯一已知路径 |
| 保底 | **F5 解析注入**（13ch 线性 modes=252，`outputs/ls_init_f1/best_model.pt`，test rl2 = 3.078e-6 官方复核 2.84e-6，余量 32-35×） | 若 T6 学习路线未能达标 → 回退注入形态（硬性门由注入保证，代价是"简易"妥协）；形态与学习路线同构（13ch 线性），回退零适配成本；**禁止对注入模型 resume 微调**（发现 9） |

### 一句话决策

**主攻 A 变体：13ch 线性（activation="none"）小型 FNO，width 64、modes 128，训练数据 = `neural_operator_3_pre` 扩产全量 5700（preroll 0.5s + substeps 5 配方同 P2）；学习极限未达 1e-4 时按 E 系列经验链式微调；最终未达标则回退 F5 解析注入保底（硬门保证）。**

## 3. 理由链（每条结论 → 证据）

1. **输入特征选 13ch（决定性，三重证据）**
   - raw 8ch：P2 档 LS 地板 0.5599 ≫ 1e-4，预滚不能救（泄漏比反升、DC 伪影）→ Ruling T4.2 出局；
   - diff8ch：分析侧 8.2e-5 余量仅 1.2×（T4 review F3）+ **训练管线 float32 地板 2.5e-3**（发现 5，超目标 25×，修复需全局 dtype 改造）→ 出局；F2 实测 9.42e-3 印证；
   - 13ch：P2 档地板 4.2e-6（余量 ~24×）、float32 免疫（发现 5）、与保底注入（F5）输入同构。
2. **线性（activation="none"）**
   - 发现 1：`f_dist = M q̈ − B u` 精确线性（rl2 ~1e-15），最优解是逐 bin 线性算子，非线性只加互调 → 非线性结构无理论收益；
   - P1：modes 128→252 无学习收益 → 学习极限与模型容量/表示无关；
   - 线性 = 参数最少、CPU 推理最快（主验收），符合"简易"。
3. **modes=128（由频谱定）+ 判定门**
   - P2 子步净化：18-250 Hz 无高频伪影、d 带能量占比 6.1e-5 → 发现 6 的截断根因（积分器伪影进目标高频 bins）应已消除 → modes=128 的截断地板应 < 1e-4；
   - P1：即使旧数据，modes 252 也未改善学习极限 → 学习路线不依赖 252；
   - 判定门：若 T6 训练后 val rl2 平台 > 1e-4 且频谱诊断指向 bins 128-251 有残余内容 → 升 modes=252（保底注入同构，零成本切换）。
4. **width=64 + 判定门**
   - spec §4 候选 A 定义 width≤64；逐 bin 映射的表示需求远低于 width 64 容量；
   - 判定门：T6 若 train 平台高且 val/train gap 小（欠拟合）→ 升 width 128；gap 大（过拟合）→ 保持。
5. **数据档扩产全量 5700**
   - P2 已实证配方正确（manifest 3.0 完整、物理一致、生成快）——扩产是纯重复操作；
   - 学习型 SGD 泛化依赖样本量；test 50 → 200 样本的评估统计更可靠（硬性门判定基于官方 evaluate 全 test）。
6. **保底 = F5 解析注入**
   - 已验证达标（3.078e-6，余量 32.5×）；形态与学习路线同构 → 学习失败时的无成本回退路径（硬性门优先于"简易"）。

## 4. 未决不确定性 → T6 消解

| 不确定性 | 证据现状 | T6 消解方式 |
|---|---|---|
| **13ch 线性全频谱的学习极限**（核心未知）：P1 500ep = 5.97e-3 vs E31（非线性 1200ep 链式微调）= 2.03e-4——线性 + 长训 + 低 lr 的极限未测 | P1 判定"优化/泛化侧瓶颈"；E31 证明训练策略可大幅改善（6e-3 → 2e-4） | 计划 Task 6 Step 2 既定：500ep 起步（与 P1 可比），未达 1e-4 做低 lr 链式微调迭代；若最终仍 >1e-4 → 回退保底注入（硬门保证），学习极限作为战役结论报告 |
| **modes=128 截断地板未直接量化**（P2 只查 18-250 Hz，bins 126-251 未测） | P2 频谱净度间接支持（d 带占比 6.1e-5） | 训练后判定门：val rl2 平台 >1e-4 时复用 analyzer/DFT 检查目标 d 的 bins 128-251 能量 → 指向截断则升 modes=252 |
| **width 64 vs 128 对学习极限的影响未测** | P1 用 128；容量非瓶颈的证据间接（modes 128→252 无差） | 训练曲线诊断：欠拟合（train 高、gap 小）→ 升 128；过拟合（gap 大）→ 保持 64 |
| **子步净化对学习型 FNO 的具体收益未量化**（P2 是 LS/频谱侧证据） | P2 13ch 地板 5.0e-6 → 4.2e-6、无伪影 | T6 结果与 P1（旧数据 5.97e-3）对比：P2 档训练显著更优 → 净化收益成立；持平 → 学习极限主导 |
| **训练样本量 500 vs 5000 的 SGD 泛化差异** | 发现 4"非样本量限制"是闭式 LS 结论，不适用 SGD | 直接采用 5700 档消除此变量（成本可忽略）；T6 快速迭代可用 500/50/50 小跑，但**小跑结果不构成正式判定**（仅形态/策略验证） |

## 5. 风险标注（T4.4 要求）

- **决策选 13ch，diff8ch 的余量风险不适用**；记录出局依据与回退条件：若 13ch 学习路线整体失败且需重新评估 diff8ch，必须满足 (a) 先解决训练管线 float32 量化地板（2.5e-3，发现 5——需全局 float64 或等效手段，与"简易"冲突）；(b) 在 T6 全 test 受控评估（train 全集 + 官方 evaluate 全 test）下复测 8.2e-5（跨数据集非受控对照）。
- **13ch 自身的余量档位**：分析侧 4.2e-6（余量 ~24×）↔ 训练侧 float32 地板 6.0e-5 @reg=1e-8（发现 5，余量 ~1.7×）——两者均低于 1e-4；学习路线的目标 1e-4 落在"学习极限（未知，~6e-3@500ep 优化瓶颈）与 LS 地板（4.2e-6~6e-5）"之间，不确定性集中于学习极限（§4 首行），由 T6 链式微调迭代消解。
